# 蒸馏实验 · 结果速览（截至 2026-09-28）

**任务**：用远程昇腾 910B 服务器上的 Qwen3-8B / Qwen3-4B 生成教师推理数据，将能力蒸馏到 Qwen3-1.7B，并在冻结考卷上做前后对比。

**当前状态**：8B 教师的 v1 与锚点混训 v2 均已完成双卷后测；4B 教师路线已完成多轮数据形态排查。最新 `distill-4b-think` 的数学 accuracy 为 **0.8233（当前最高）**，考卷一 MCQ400 尚待补测。

## 当前结论

1. **v2 mix 很早已经测完，不是当前待办。** 它把 v1 的通用 accuracy 从 0.5925 回收到 0.63，与前测 0.64 仅差 1pt，同时数学仍比前测高 3pt。29% 的 MMLU val 锚点配比已达到目标。
2. **4B 教师早期失败的主因不是参数量，而是推理信号在数据管道中丢失。** Qwen3-4B 会把大量过程写在 `<think>` 中，可见区只留答案；含 62 条裸答案的数据把学生教成了跳步骤。过滤后数学从 0.4167 回升到 0.5867，保留完整思考链后进一步升到 0.8233。
3. **4B-think 证明了完整推理链的价值，但不是零代价。** 300 题中 247 题正确；267 条规范收尾题答对 246 条（0.9213），33 条撞到 2048 token 上限，仅 1 条答对。总耗时约 82 分钟，截断率 11%。相对基线的逐题配对提升成立（McNemar exact p=0.0019），相对 4B-v2 更是大幅反转；但它相对 8B-v1 只净多 6 题（p=0.4614）、相对 8B-v2 mix 净多 10 题（p=0.2026），所以只能称“当前点估计最高”，不能称已显著超过两条 8B 路线。
4. **目前不能称 4B-think 为综合最优。** 它的数学成绩最高，但考卷一尚未跑；只有通用能力结果出来后，才能判断是否超过双卷已闭环的 8B-v2 mix。
5. **归因边界**：4B-think 相对 canonical 同时改变了训练文本形态与 cutoff（1024→2048），所以 23.66pt 提升不能全部归因于 `<think>` 标签本身；可以可靠支持的结论是“保留更多真实推理 token 显著优于只训练压缩后的可见区”。

## 评测协议

- 考卷二：GSM8K test 固定 300 题，temperature=0、batch=8、max_new_tokens=2048。
- 考卷一：CMMLU 200 + MMLU 200，正式协议保持思考模式开启、max_new_tokens=2048。
- 前后测只替换 LoRA adapter；考卷、prompt、解码参数与 batch 保持不变。
- 脚本每批写入 partial，支持按模型与 adapter 校验后的断点续跑。
- 数学报告保留逐题抽取方式与原始可见尾部；4B-think 的 0.8233 按冻结脚本口径计算，包含截断题的既有降级抽取。
